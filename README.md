# なんこの大冒険

[ゲームを遊ぶ](https://mokamoka20111115-lang.github.io/nanko-adventure/)

無料で遊べる、なんこ＆ちゃけのシューティング＋第2章RPG。HTML・CSS・JavaScriptだけで動き、アカウントや有料APIは不要です。

## 第1章：全3ステージのシューティング
- スマホ：画面をドラッグで移動、自動射撃。PC：矢印/WASD、1/2/3で武器、Z/Xで必殺技、Pで一時停止。
- iPhoneの一時停止は上部ボタンを0.75秒長押し。スライドや短い誤タップでは停止しません。
- **おかね**：初期武器。基礎威力6、連射間隔0.16秒。
- **うるふぎゃんぐ**：ステージ1の敵3体目から肉アイテムが出現。取り逃した場合も未解放の間は5体ごとに再出現。取得して解放すると切り替え可能。解放は保存されます。
- **子持ちあゆ**：通常敵撃破時3%抽選のレアな魚アイテム。取得で30秒、自動装備。残り秒数をボタンに表示し、終了後は以前の通常武器に戻ります。再取得は残り30秒へ更新。一時停止中は減りません。
- ハート＝回復、黄色い星＝強化、紫の星＝必殺技ゲージ。ボス戦にも18秒ごとに回復が出現します。
- ボスHPは1800／2400／6000。通常敵もHP2倍。HPに応じて攻撃が変化。はしもとは70%・40%・15%未満で強くなる4段階、眼鏡フラッシュの予告線から避けよう！
- ステージクリア時に次ステージの開始地点を自動保存。ゲームオーバー・再起動後はそのステージから、HP3で再開。パワーとスコアは開始地点へ戻り、魚の残り時間は持ち越しません。

## 武器とちゃけの強化（第2次調整）
- おかね：24%で壁に最大2回反射するコイン。POWER 2で2方向、3で3方向になり、連射も速くなります。単発の威力は小さめ。
- 肉：遅い高威力弾と周囲への爆風。18%で巨大肉になり、直撃1.4倍・爆風範囲拡大。狭い射線を合わせる必要があります。
- 魚：回転する3方向弾。35%の弾は最大3体を貫通。同じ敵には1発につき1回だけダメージ。30秒限定。
- はしもと：追尾名刺、回転書類、戻るネクタイ、方向反転、左右挟撃。約1秒の予告を表示。追尾は1.25秒で止まり、後半はネクタイと複合します。眼鏡フラッシュはさらに予告線が出ます。
- **羽（黄色）**：敵撃破時5%、ちゃけが3方向射撃。45秒。
- **頬（オレンジ）**：敵撃破時5%、ちゃけの威力2倍。45秒。
- **覚（紫）**：敵撃破時2%、ちゃけが自動追尾弾を0.24秒ごとに発射。20秒。
- ちゃけ強化3種は併用可能。同種の再取得は残り時間を上限へ更新するだけで、方向数・威力倍率を加算しません。通常射撃は威力9／0.52秒、覚醒は11／0.24秒、ほっぺ併用でも最大22／発です。
- 残り時間は画面下に表示。一時停止・ステージクリア演出中は減らず、リトライ・再起動・RPG遭遇戦開始ではリセットします。ステージ間は残り時間を持ち越します。

## 第2章：なんこ、ニッショーに出勤する！
第1章クリア後に「第2章・ニッショーへ出勤！」を選びます。
1. 公園の左下で社員証を拾う。
2. おべんとう屋さんからお弁当をもらう。
3. 会社前の受付さんと話し、書類のシューティングバトルをクリア。
4. ニッショーの玄関を調べて出勤成功！

スマホは行きたい場所をタップすると建物を避けて移動。PCは矢印/WASD。近くで「話す・調べる」またはEnter/Spaceで会話・収集します。ちゃけは後ろをついてきて応援します。
街での位置・アイテム・ミッションは自動保存。遭遇戦で負けたらその戦闘から再挑戦できます。遭遇戦の途中でアプリを閉じた場合は街から再開します。
第2章クリア後も街を歩けます。第3章以降の新しいステージ・街は今後追加する内容です。

## セーブと「最初から遊ぶ」
進行は同じ端末・同じブラウザのlocalStorageにのみ保存します。他の端末や別ブラウザとは同期しません。
「最初から遊ぶ」には確認画面があり、章と武器の進行をリセットします。ベストスコアと消音設定は維持します。
ブラウザのサイトデータ削除・プライベートブラウズ・iOSのストレージ整理では進行を失う場合があります。保存に失敗した場合は画面に表示します。

## iPhoneに追加・オフライン
Safariで公開ページを開き、共有→ホーム画面に追加→追加。
「オフライン準備OK」を確認してからオフラインにしてください。更新後は通信できる状態で一度開き、ゲーム終了後にタブやホーム画面アプリを閉じて開き直してください。画面下の「第2次バランス v2」が新版の目印です。旧版が残る場合は[新版リンク](https://mokamoka20111115-lang.github.io/nanko-adventure/?v=balance-2)を一度開いてください。セーブデータを消す必要はありません。
音は最初の操作後に開始。日本語音声合成が使えない端末でも文字と効果音が出ます。
iPhone実機のSafari・ホーム画面起動・音声再生は開発環境では未検証です。

## 構成・運用
- `game.js`：既存シューティング、キャラ描画、音、章の切り替え。
- `rpg.js`：第2章のマップ・会話・移動・ミッション。共有描画関数を受け取り、遭遇戦を呼び出します。
- `progress.js`：バージョン付きセーブの検証・保存。外部通信なし。
- `service-worker.js`：画像・アイコン・両モードのコードをオフライン保存。
- `DEVELOPMENT.md`：今回の検証結果、未確認事項、続きの作業場所。

mainへのpushで標準のubuntu-latest上のGitHub ActionsからGitHub Pagesへ静的ファイルを公開します。公開リポジトリの構成を維持し、有料の実行環境やサービスを追加していません。
開発用テストにはNode.js、Playwright、@napi-rs/canvasを使用しますが、ゲーム本体には外部ライブラリを配信しません。
